# Evidências (prints)

Salve os prints de tela aqui, um arquivo por bug, nomeado exatamente como o ID:

```
BUG-001.png
BUG-002.png
BUG-003.png
BUG-004.png
...
```

O BUGS.md já referencia essas imagens automaticamente (`![BUG-XXX](evidencias/BUG-XXX.png)`) —
assim que o arquivo existir aqui com o nome certo, ele aparece embutido ao abrir o BUGS.md
no VS Code (Ctrl+Shift+V para pré-visualizar o markdown) ou no GitHub/GitLab.

Se preferir outro formato de imagem (.jpg, .gif), só trocar a extensão no link
correspondente dentro de BUGS.md.
